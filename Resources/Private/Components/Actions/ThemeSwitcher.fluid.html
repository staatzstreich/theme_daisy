Without a `themes` argument the component renders the 35 built-in daisyUI themes. That list is the three-way source of truth and MUST stay in sync with: 1. Resources/Private/Assets/Css/main.css (@plugin "daisyui" themes block), 2. Configuration/Sets/ThemeDaisy/settings.definitions.yaml (enum). Each menu entry carries a small swatch rendered in the entry's own theme (daisyUI applies data-theme on any container), so the list previews every theme. Active sync happens client-side in theme-daisy.js via [data-theme-value]; the server cannot know the visitor's stored theme.
