The active theme is stamped as data-theme on the element: - server-side default from the site setting theme.daisy.defaultTheme (see Configuration/Sets/ThemeDaisy/setup.typoscript), - visitor override applied inline in the head below (no flash of the default theme) and kept in sync on navigation by theme-daisy.js. (function () { try { var storedTheme = localStorage.getItem('theme-daisy-theme'); if (storedTheme) { document.documentElement.setAttribute('data-theme', storedTheme); } } catch (e) { // localStorage unavailable - server-rendered default stays active } })();
Built with TYPO3 and daisyUI.
